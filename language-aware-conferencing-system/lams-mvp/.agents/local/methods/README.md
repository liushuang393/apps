# Language / framework method overrides

One file per language or framework. This directory ships empty on purpose.

A method file narrows a capability from `.agents/core/common/method-router.md` for this
repository — how TDD is actually done here, what the debugging loop looks like, which
seams exist. It does not replace the workflow; it replaces the *technique*.

Suggested names: `python.md`, `typescript.md`, `java.md`, `go.md`, `rust.md`,
`react.md`, `spring.md`.

Keep each file to what an engineer new to this repository could not guess.
