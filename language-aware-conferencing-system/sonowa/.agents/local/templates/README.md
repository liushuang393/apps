# Artifact templates

Optional per-artifact templates. This directory ships empty on purpose.

If a file here matches an artifact name a workflow produces
(`01-basic-design.md`, `02-detailed-design.md`, `03-implementation-report.md`,
`04-verification-report.md`, `01-diagnosis.md`, …), the workflow uses it as the
skeleton instead of its built-in structure.

Use this when the organization has a mandated document format.
