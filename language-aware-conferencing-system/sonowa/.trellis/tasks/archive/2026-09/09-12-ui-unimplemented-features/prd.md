# 画面未実装機能を接続する

## Goal

メニューに見える「準備中」と、会議記録・管理画面で欠落している既存 API を接続し、利用者がプロフィール変更・参加履歴確認・議事録生成・用語集管理・離線 rerun を画面から行えるようにする。

## Background

- メニューのプロフィール・利用履歴は Coming Soon スタブで、ルートも API 自己更新もない。
- `GET /api/rooms/{id}/minutes` と `/api/glossaries/terms`、`POST /api/admin/sessions/{id}/rerun` は実装済みだが UI 未接続。
- 管理者ユーザー編集は `nativeLanguage` を既に送信できるが、モーダルに母語入力がない。
- `participant` 表は参加の耐久記録であり、利用履歴の一次ソースになる。

## Requirements

- R1: 認証済みユーザーは表示名と母語を自己更新でき、更新後の JWT に新しい母語が入る。
- R2: 認証済みユーザーは自分が参加した会議室の履歴を一覧し、会議記録へ遷移できる。
- R3: 会議記録画面から議事録（要約・決定・ToDo）を生成できる。LLM 未設定時は理由を表示する。
- R4: 管理者はユーザー編集モーダルで母語を変更できる。
- R5: 管理者は用語集を一覧・作成・更新・削除できる。
- R6: 管理者は会議記録画面から選択中セッションの離線 rerun を実行できる。本地モデル未導入時は 503 理由を表示する。
- R7: メニューの「準備中」バッジをプロフィール・利用履歴から外し、用語集への管理者導線を追加する。

## Acceptance Criteria

- [x] AC1: `/profile` で表示名・母語を保存するとメニュー表示名が更新され、再ログイン不要で新しい JWT が使われる。
- [x] AC2: `/history` に自ユーザーの参加部屋だけが出る。他ユーザーの参加は混ざらない。空状態がある。
- [x] AC3: 会議記録の「議事録を生成」で要約・決定・ToDo が出る。503 時は LLM 未設定と分かる。
- [x] AC4: 管理者ユーザー編集で母語を保存すると一覧の言語列が更新される。
- [x] AC5: `/admin/glossary` で用語 CRUD ができ、`do_not_translate` 時は訳語任意、それ以外は必須。
- [x] AC6: 管理者のみ会議記録に「離線再処理」が出る。成功時は件数、503 時は本地モデル未導入と分かる。
- [x] AC7: メニューからプロフィール・履歴・用語集（管理者）へ遷移でき、「準備中」は付かない。

## Out of Scope

- S2S / `language_routes` トグル、招待リンク、録音、会議室編集削除
- 会議画面 i18n の全面配線、パスワードリセットの本番メール
- `.env` / compose / Dockerfile の変更
- パスワード変更（既存リセット導線を使う）
- 会議回ごとの履歴拡張、`tenant_id` 用語集 UI
