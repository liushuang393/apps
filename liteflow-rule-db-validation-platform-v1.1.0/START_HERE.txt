LiteFlow Rule-DB Validation Platform 1.1.0

--------------------------------------------------------------------
最短手順（Windows）
--------------------------------------------------------------------
1. Docker Desktop を起動し、アイコンが緑になるまで待つ。
2. このZIPを短いASCIIパスへ展開する。
   例: C:\work\liteflow-rule-db-validation-platform-v1.1.0
3. scripts\run-all.cmd をダブルクリックする。
4. 成功でも失敗でもウィンドウは開いたままになる。
5. reports\validation-report.md を開いて総合判定を確認する。

--------------------------------------------------------------------
最短手順（WSL / Linux）
--------------------------------------------------------------------
1. Docker Engine または Docker Desktop 連携が動いていることを確認する。
2. chmod +x scripts/*.sh && ./scripts/run-all.sh
3. reports/validation-report.md を確認する。

--------------------------------------------------------------------
Docker を使わずに動作だけ見たい場合
--------------------------------------------------------------------
ホストに JDK と Maven があれば、約20秒でビルドとテストを確認できる。
   scripts\local-verify.cmd        → reports\local-verify.json

注意
--------------------------------------------------------------------
reports\preflight-report.md は配布時点の静的検査結果であり、
Docker と MariaDB による E2E の成功を意味しない。
実行時の PASS は run-all.cmd / run-all.sh だけが生成する。

機能ごとの詳しい手順は README.md の「手順索引」を参照すること。
